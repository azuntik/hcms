# About This Site

This is a Hugo static website managed by Flutter CMS - a modern, user-friendly content management system.

## Our Mission

To make static site management as easy as traditional CMS platforms, while maintaining the performance and security benefits of static sites.

## Technology Stack

- **Hugo**: Fast static site generator
- **Flutter Web**: Modern web interface
- **Gitea**: Self-hosted Git version control
- **Rsync**: Reliable deployment
